## 🌟 Características Destacadas

- **Diseño Moderno y Deportivo-Tecnológico**: Estética visual de alto impacto que combina la energía del deporte de alto rendimiento (MTB, pistas, activaciones) con la precisión digital del desarrollo web.
- **Fotografías Reales en Alta Resolución**:

  - Estilos de impresión optimizados (`Ctrl + P` o botón de imprimir) para generar una versión limpia en papel o PDF.

- **Botones de Contacto Directo**:

  - Correo electrónico: `jmorabowen@gmail.com` con enlace directo y botón de copiar.

- **100% Responsive**: Diseñado y probado para celulares, tablets y pantallas de escritorio.
- **Cero dependencias pesadas**: Construido con HTML5 semántico, CSS3 moderno y Vanilla JavaScript nativo.

## 🚀 Cómo Abrir y Usar la Página

### 1. Directamente en tu Navegador
Solo haz doble clic en `index.html` o ábrelo con Google Chrome, Microsoft Edge, Brave, Firefox, etc. ¡No requiere instalar nada!

### 2. Cómo Publicarlo Gratis en Internet (Hosting)
Puedes publicar esta página web en menos de 2 minutos gratis con:
- **GitHub Pages**: Sube los archivos a un repositorio y activa *Pages* en la configuración.
- **Vercel / Netlify**: Arrastra la carpeta `juan-valdivieso-cv` a [Netlify Drop](https://app.netlify.com/drop) para tener un link público al instante (ejemplo: `juanmartin-cv.netlify.app`).
